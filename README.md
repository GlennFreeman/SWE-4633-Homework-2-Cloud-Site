# Assignment 3
For Assignment 3, you will expand on your work in Assignment 2. You will add the following components to your web app and server software:

 1) You will set up a database on your cloud platform.

 2) The database will be used to replace the hardcoded processes from Assignment 2. Your site will now retrieve the data to display from information stored in the database, and it will update and retrieve user-submitted information.

 3) You will properly sanitize data from the user, on both the client and server side of the web app.

 4) You will add a log-in feature to your site. When the user is logged in, you will display some personalization on the site (such as "Hello <Username>" in the navigation bar of the site)

 5) The log-in feature will use [OpenID Connect](https://openid.net/developers/how-connect-works/) (built on top of OAuth2 for authentication).

## Deliverables

- Source code for both front-end client and server-side code (hosted on your code repo)
- Working public URL for the front-end client
